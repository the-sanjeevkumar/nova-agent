Skills for sending, receiving, searching, and managing email from the terminal.

Built-in `email_search` / `email_read` / `email_folders` / `email_send` model tools cover the
configured mailbox directly when the email channel is set up (EMAIL_*); reach for the skills below
when those tools are unavailable or the connector surface (labels, filters, terminal workflows) is
the requirement.
